How it works

From Windows installation to OOBE.

One flow. Your apps and configuration, applied before OOBE.

  1. 01

    Windows deployment · WinPE

    Install Windows

    Apply Windows with OSDCloud or another deployment method. The examples use OSDCloud.

  2. 02

    OSDStage · WinPE

    Stage your choices

    Stage the apps and configuration you choose. If an OSDCloud-labeled USB drive is connected, supported content can be cached and reused automatically.

  3. 03

    Windows 11 · SetupComplete

    Apply automatically

    Restart into Windows. SetupComplete installs your apps, runs Windows Update when selected and applies configuration before OOBE.

  4. 04

    Windows 11 · OOBE

    Continue setup

    Review your delivery report, then continue with Windows setup, Autopilot device preparation, classic Autopilot or your own provisioning flow.
